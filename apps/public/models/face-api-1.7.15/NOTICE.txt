The 128D face recognition network uses the Davis King/dlib recognition
weights converted to TensorFlow.js format by face-api.js. The original
face-api.js README attributes these weights to Davis King. Davis King's
model repository explicitly releases the face recognition model public
domain; its license is CC0-1.0. See LICENSE.dlib-models.txt and:
https://github.com/davisking/dlib-models
https://github.com/justadudewhohacks/face-api.js#face-recognition-model

The bundled neural face_landmark_68_tiny model is NOT dlib's
shape_predictor_68_face_landmarks.dat. The latter is not bundled or used.

Only these six model files are used: tiny_face_detector_model.bin and its
manifest, face_landmark_68_tiny_model.bin and its manifest,
face_recognition_model.bin and its manifest. Exact byte lengths/SHA256
are in ../manifest.json and client/vision/model-assets.ts. Runtime
fetches same-origin files only and verifies these hashes before decoding.

No real participant accuracy or timing is established by loading these
models. Session calibration requires consenting real captures; held-out
recognition, unknown rejection, crossing and device checks remain separate.
